# mace-amsulf-data

## Overview

This repository contains input files, training data, and trained MACE models used in the study:

"Barocaloric phase transformation from data efficient fine-tuning of machine learned interatomic potentials"
Hedin L., and Klarbring J. (2026)

---

## Repository contents

- `datasets/` – Datasets sets used in training and evaluation of MACE models
- `models/` – Trained MACE models
- `simulations/` – Input files for MD simulations using the I-Pi package
- `training/` – Input files for MACE training

---

## Data availability

All data, simulation input files, training datasets, and trained models are available in this repository:

https://github.com/Snurre3/mace-amsulf-data
